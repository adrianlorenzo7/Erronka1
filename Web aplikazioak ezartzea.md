### WordPress Erabiltzailea Kudeatzea (Ubuntu Zerbitzarian)

Ubuntu zerbitzari batean WordPress ingurunea prestatu eta gero, urrats hauek jarraitu ditugu pantaila honetara iristeko:

1. **WordPress Ubuntu-n konfiguratu eta sartu gara:** Ubuntu zerbitzarian WordPress instalatu eta gero, nabigatzailean gure zerbitzariaren IP bidez panel nagusira sartu gara.
2. **Erabiltzaileen atalera joan gara:** Ezkerreko menuan **Erabiltzaileak (Usuarios)** hautatu eta **Erabiltzailea gehitu (Añadir usuario)** sakatu dugu.
3. **Formularioa bete eta rola esleitu dugu:** Erabiltzaile berriaren datuak sartu ditugu (`finantzak_1` kasu honetan) eta bere lanpostuari dagokion rola (*Editor*) esleitu diogu.
4. **Sorkuntza berretsi dugu:** Formularioa bidali ondoren, sistemak erabiltzaile berria ondo sortu dela berretsi digu (*Nuevo usuario creado*) eta zerrenda orokorrenean aktibatuta agertu zaigu.

### Webgunearen Diseinua eta Pertsonalizazioa

Atariari itxura profesionala eta korporatiboa emateko, urrats hauek jarraitu ditugu:

1. **Oinarrizko txantiloia hautatu dugu:** **Atlas** txantiloia hartu dugu gure webgunearen oinarri eta egitura nagusi gisa.
2. **HTML eta CSS bidez editatu dugu:** Txantiloi horren kodea geure erara egokitu dugu; HTML egitura aldatu dugu Orbis-en edukiak (adibidez, *Jasangarritasun plana*) txertatzeko eta CSS estiloak moldatu ditugu gure marka-koloreak, letra-tipoak eta nabigazio-menua ezartzeko.
3. **Azken emaitza:** Pertsonalizazio lan honen ondoren, webgunea argazkian ikusten den moduan geratu da, atal desberdinak garbi eta antolatuta erakutsiz.

### GLPI Inbentario-Sistemaren Instalazioa eta Kudeaketa (Ubuntu)

Gure azpiegitura teknikoaren baliabideak eta inbentarioa kudeatzeko, urrats hauek jarraitu ditugu:

1. **GLPI Ubuntu Zerbitzarian instalatu dugu:** Ubuntu zerbitzarian GLPI plataforma konfiguratu dugu, gure IT lanabesen eta ekipoen inbentarioa erregistratzeko.
2. **Aktiboen atalera joan gara:** Behin web interfazean sartuta, ezkerreko menuan **Activos > Ordenadores** atala hautatu dugu ekipoak kudeatzeko.
3. **Makina Birtuala erregistratu dugu:** Argazkian ikusten denez, gure **`Ubuntu Server Erronka`** makina birtuala gehituta utzi dugu, mota gisa *Máquina Virtual* ezarriz eta azken eguneraketa-data erregistratuz.
