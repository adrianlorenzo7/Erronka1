### WordPress Erabiltzailea Kudeatzea (Ubuntu Zerbitzarian)

Ubuntu zerbitzari batean WordPress ingurunea prestatu eta gero, urrats hauek jarraitu ditugu pantaila honetara iristeko:

1. **WordPress Ubuntu-n konfiguratu eta sartu gara:** Ubuntu zerbitzarian WordPress instalatu eta gero, nabigatzailean gure zerbitzariaren IP bidez (`192.168.10.3/wp-admin`) panel nagusira sartu gara.
2. **Erabiltzaileen atalera joan gara:** Ezkerreko menuan **Erabiltzaileak (Usuarios)** hautatu eta **Erabiltzailea gehitu (Añadir usuario)** sakatu dugu.
3. **Formularioa bete eta rola esleitu dugu:** Erabiltzaile berriaren datuak sartu ditugu (`finantzak_1` kasu honetan) eta bere lanpostuari dagokion rola (*Editor*) esleitu diogu.
4. **Sorkuntza berretsi dugu:** Formularioa bidali ondoren, sistemak erabiltzaile berria ondo sortu dela berretsi digu (*Nuevo usuario creado*) eta zerrenda orokorrenean aktibatuta agertu zaigu.
